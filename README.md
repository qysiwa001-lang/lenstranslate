# 译镜 LensTranslate

打开相机对准外语文字，一键识别并翻译成中文。

## 功能

- 相机实时取景，拍照翻译（也可从相册上传图片）
- 支持识别：英语 / 日语 / 韩语 / 法语 / 意大利语 / 西班牙语 / 德语 / 葡萄牙语 / 俄语 / 越南语 / 泰语 / 阿拉伯语，默认自动检测
- 识别原文 + 中文译文对照显示，一键复制
- 本地保存最近 50 条翻译历史
- 内置示例图，无摄像头也能体验完整流程

## 使用方法

双击 `启动译镜.bat`，浏览器会自动打开 http://localhost:8630

> 浏览器安全策略要求：相机只能在 localhost 或 HTTPS 环境下使用，
> 直接双击 index.html（file:// 协议）时相机不可用，但仍可用相册上传。

首次识别某种语言时会自动下载对应的 OCR 语言模型（几 MB），
下载一次后浏览器会缓存，之后离线也能识别（翻译仍需联网）。

## 技术说明

- OCR：Tesseract.js（纯前端，语言模型按需加载并缓存到浏览器 IndexedDB）
- 翻译：Google Translate 公开接口优先，失败时自动切换 MyMemory 备用引擎
- 数据：翻译历史仅保存在本机浏览器 localStorage，不上传任何服务器
- 除 Tesseract.js CDN 外无其他外部依赖
